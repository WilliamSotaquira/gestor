# Wireframes · Navidad con Prudencia (Secretaría de Movilidad)

Dos propuestas de baja fidelidad para el micrositio de una sola página (Inicio, Recomendaciones, Actividades, Acciones). Los accesos son anclas dentro de la misma página. Todo dato de fechas, lugares, horarios y cifras es de prueba y está marcado con la etiqueta amarilla "DATOS DE PRUEBA". No es el sitio final.

## Cómo abrirlos
Doble clic sobre el archivo HTML (no requiere instalación ni compilación). Son responsive: para ver la versión móvil, reduzca la ventana o use las herramientas del navegador.

| Propuesta | Archivo | Enfoque |
|---|---|---|
| A | `E:\gestor\docs\wireframes\navidad-con-prudencia\propuesta-a-tarjetas.html` | Página larga con menú superior fijo, portada con imagen grande y todo en tarjetas: perfiles, actividades y acciones numeradas. Visual, para explorar. |
| B | `E:\gestor\docs\wireframes\navidad-con-prudencia\propuesta-b-lateral.html` | Menú lateral fijo (en móvil pasa a barra superior), portada textual, perfiles y acciones en acordeones, actividades en tabla comparativa (en móvil se apilan). Informativa y compacta. |
